# 🌸 Blooming Spiral – Python Flower Animation

### 🌼 Project Description

A mesmerizing flower animation created using **Python Turtle Graphics**. This project uses mathematical functions, trigonometry, and circular patterns to generate an elegant spiral flower that gradually blooms on a black background.

The animation combines **creativity, mathematics, and programming** to transform simple geometric shapes into beautiful generative art.

### 🛠️ Technologies Used
- **Python** – Main programming language
- **Turtle Graphics** – Drawing and animation
- **Math Module** – Trigonometric calculations and spiral patterns
- **Time Module** – Controlling animation speed

### ✨ Features
- Smooth, step-by-step flower animation
- 11 symmetrical spiral arms
- Mathematical patterns using sine and cosine
- Minimalist black-and-white design
- Real-time drawing effects

### 🎯 Project Goal

To explore creative coding and demonstrate how Python can transform mathematical equations into captivating visual animations.
